# 「差不多」文案规格（单一事实来源）

> 一切文案、时间点、设置项**以本文件为准**。微调流程：先改本文件 → 再改代码/字符串 → 编译 → 重发 beta。
> 配套：`resources-zho/strings.xml`（文案）、`docs/学习笔记.md`（术语与流程）、`项目台账.md`（状态）。

## 版本规则

- 微调（文案/时间点/默认值）→ `v1.0.x`，CHANGELOG 一行
- 新功能 → `v1.x`；重大重设计 → `v2.x`
- 每次改动：更新本文件 → commit → 重编译 → 重发 beta（beta 即时生效，无商店审核）

## 1. 时间模板（12 条，tab 决定排版拆行：`主体<TAB>修饰`=两行；无 tab=单行）

| 模板 | 文案 | 拆行效果 | 语义覆盖 |
|---|---|---|---|
| min0 | `$1$整` | 单行 | 整点 |
| min5 | `$1$`␉`过五分` | 一点 / 过五分 | 3–7 分 |
| min10 | `$1$`␉`过十分` | 一点 / 过十分 | 8–12 分 |
| min15 | `$1$`␉`一刻` | 一点 / 一刻 | 13–17 分 |
| min20 | `$1$`␉`过二十分` | 一点 / 过二十分 | 18–22 分 |
| min25 | `快到`␉`$1$半咯` | 快到 / 一点半咯 | 23–27 分 |
| min30 | `$1$半` | 单行 | 28–32 分 |
| min35 | `$1$`␉`三十五分` | 一点 / 三十五分 | 33–37 分（名义值） |
| min40 | `差二十分钟`␉`$2$` | 差二十分钟 / 两点 | 38–42 分 |
| min45 | `差一刻`␉`$2$` | 差一刻 / 两点 | 43–47 分 |
| min50 | `差十分钟`␉`$2$` | 差十分钟 / 两点 | 48–52 分 |
| min55 | `差五分钟`␉`$2$` | 差五分钟 / 两点 | 53–57 分 |

- `$1$`=当前小时词，`$2$`=下一小时词；槽位取整 `((min+2)/5)*5`，58–59 分进位下一小时。
- 小时词：一点…十一点；**12 点整显示「中午啦」、0 点整显示「半夜啦」（仅整点槽位）**；其余时刻用 `十二点`/`零点`（模板小时词，hour12Word/hourZeroWord）。
- min35「一点三十五分」为名义值（覆盖 33–37 分），保留（已确认）。

## 2. 猪猪时刻（工作日=周一至周五，周末自动不生效）

开关名「猪猪时刻」，**默认开**；关闭后无特殊短语、无数字时间。

| 时段 | 主显示 | 底部 |
|---|---|---|
| 8:10–8:19 | 正常短语 | 数字时间 + 日期星期 |
| 8:20–8:30（含 8:30） | 上班打卡 | 数字时间 + 日期星期 |
| 8:31–8:40 | 正常短语 | 数字时间 + 日期星期 |
| 16:30–16:39 | 正常短语 | 数字时间 + 日期星期 |
| 16:40–16:44 | 差二十分钟下班 | 数字时间 + 日期星期 |
| 16:45–16:49 | 差一刻下班 | 数字时间 + 日期星期 |
| 16:50–16:54 | 差十分钟下班 | 数字时间 + 日期星期 |
| 16:55–16:59 | 快下班啦 | 数字时间 + 日期星期 |
| 17:00–17:04 | 下班！ | 数字时间 + 日期星期 |
| 17:05–17:30 | 正常短语 | 数字时间 + 日期星期 |
| 其他 | 正常短语 | 日期星期 |

- 时间点集中在 View.mc 顶部配置数组（piggyEvents），改时间点只动配置。
- 数字时间 24 小时制（`16:42` 式：小时不补零、分钟补零），显示在日期行上方。
- 边界按精确分钟判定（非槽位）：8:20:00–8:30:59、16:40:00–17:04:59。

## 4. 布局（fr57047mm，454×454 AMOLED）

```
顶部：状态图标 + 电量百分比（showBattery 控制，位置在图标右侧）

底部：数字时间（仅猪猪窗口，24h）+ 日期星期（恒显，格式 2026年8月25日 周二）
```
